# Frontend

Interfaz web de Aula desarrollada con Vue 3, Quasar y Vite.

Para instalación, variables locales, inicio del backend/frontend y preparación de la base, consulta la [guía de puesta en marcha del proyecto](../pasos.md).

Comandos desde esta carpeta:

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

La aplicación espera la API en `http://localhost:3000` durante el desarrollo.
